# Items reference

The item builder.

## ItemBuilder

- <a id="ItemBuilder-modifier"></a>`.modifier(m: crate::Modifier)`: An attribute modifier its holder gets while it is in the main hand, or `.worn()` in an equipment slot (`Modifier`). [source](https://github.com/Weft-Rust/Weft/blob/master/crates/sdk/src/content.rs#L2658)
- <a id="ItemBuilder-condition"></a>`.condition(f: impl Fn(&abi::ItemStack, &mut Looks) + Send + Sync + 'static)`: How a stack of it looks by what is in it, decided once per kind of stack (its data): `.condition(|s, v| if s.wear() > 0 { v.texture("can_empty"); })`. Other players' hands show the usual look: their stacks aren't sent. [source](https://github.com/Weft-Rust/Weft/blob/master/crates/sdk/src/content.rs#L2664)
- <a id="ItemBuilder-texture"></a>`.texture(t: &str)`: Its only picture (under `item/`; without one: the item's name), the layers given so far dropped: `.texture("ingot").tint(0xC0C0FF)`. [source](https://github.com/Weft-Rust/Weft/blob/master/crates/sdk/src/content.rs#L2678)
- <a id="ItemBuilder-layer"></a>`.layer(t: &str)`: One more picture on top, the first at the bottom: a tool made of parts, `.layer("handle").layer("head").tint(0xFF8800)`. The first replaces its own picture. Stacks can still show their own (`with_layers`). [source](https://github.com/Weft-Rust/Weft/blob/master/crates/sdk/src/content.rs#L2684)
- <a id="ItemBuilder-tint"></a>`.tint(color: u32)`: Tints the layer just added `0xRRGGBB` (its own picture if none was), multiplied: white parts take the color. One picture for many items of a color. [source](https://github.com/Weft-Rust/Weft/blob/master/crates/sdk/src/content.rs#L2690)
- <a id="ItemBuilder-max_stack"></a>`.max_stack(n: u32)`: Stack size (`max_stack`). [source](https://github.com/Weft-Rust/Weft/blob/master/crates/sdk/src/content.rs#L2721)
- <a id="ItemBuilder-animations"></a>`.animations(name: &str)`: Its clips, from `animations/<name>.animation.json`; a file named after the item is used even without this. They play on whoever holds it. [source](https://github.com/Weft-Rust/Weft/blob/master/crates/sdk/src/content.rs#L2726)
- <a id="ItemBuilder-two_handed"></a>`.two_handed()`: Needs both hands: while the other holds something it does nothing, and it can't go in the other hand. Its `hold` action shows the two. [source](https://github.com/Weft-Rust/Weft/blob/master/crates/sdk/src/content.rs#L2732)
- <a id="ItemBuilder-one_handed_action"></a>`.one_handed_action(action: &str)`: A `two_handed` item may be held in one hand after all, playing this action. It goes in the other hand then too. [source](https://github.com/Weft-Rust/Weft/blob/master/crates/sdk/src/content.rs#L2737)
- <a id="ItemBuilder-use_priority"></a>`.use_priority(priority: i32)`: On a right click the hand whose item has the higher priority goes first, whichever hand that is (default 0, then the main hand first). The other hand gets its turn when this item does nothing: a bow with no arrows. [source](https://github.com/Weft-Rust/Weft/blob/master/crates/sdk/src/content.rs#L2746)
- <a id="ItemBuilder-durability"></a>`.durability(d: u32)`: Uses before it breaks (`durability`); damageable items do not stack. [source](https://github.com/Weft-Rust/Weft/blob/master/crates/sdk/src/content.rs#L2750)
- <a id="ItemBuilder-tool"></a>`.tool(class: &str, level: u32)`: A tool of `class` (tag `tools/<class>`): it mines blocks `mined_by` that class, at its `mining_speed`, harvesting those needing up to `level` (`tool_level`). Held like one. [source](https://github.com/Weft-Rust/Weft/blob/master/crates/sdk/src/content.rs#L2755)
- <a id="ItemBuilder-handheld"></a>`.handheld()`: Held like a tool in third person, by its end and pointing ahead (tag `handheld`, vanilla's `item/handheld` model), instead of flat in the hand. Tools have it already. [source](https://github.com/Weft-Rust/Weft/blob/master/crates/sdk/src/content.rs#L2761)
- <a id="ItemBuilder-mining_speed"></a>`.mining_speed(speed: f32)`: How fast it mines its class's blocks (vanilla wood 2 ... gold 12). [source](https://github.com/Weft-Rust/Weft/blob/master/crates/sdk/src/content.rs#L2765)
- <a id="ItemBuilder-sweeps"></a>`.sweeps()`: A full swing on the ground also hits what stands next to the target, like a sword. [source](https://github.com/Weft-Rust/Weft/blob/master/crates/sdk/src/content.rs#L2769)
- <a id="ItemBuilder-no_creative_break"></a>`.no_creative_break()`: For fighting: in creative it doesn't break blocks, as a sword in modern. Client and server both know, so nothing flickers. A rule that depends on more is `actions::BREAK_BLOCK`. [source](https://github.com/Weft-Rust/Weft/blob/master/crates/sdk/src/content.rs#L2774)
- <a id="ItemBuilder-use_ticks"></a>`.use_ticks(ticks: u32)`: Takes effect after holding the use button this many ticks (food 32), slowing the player down. [source](https://github.com/Weft-Rust/Weft/blob/master/crates/sdk/src/content.rs#L2778)
- <a id="ItemBuilder-use_until_released"></a>`.use_until_released()`: Held as long as the use button is, slowing the player down, with nothing at the end: `on_release` says what letting go does after how long (a bow, a charged spear). [source](https://github.com/Weft-Rust/Weft/blob/master/crates/sdk/src/content.rs#L2783)
- <a id="ItemBuilder-on_release"></a>`.on_release(f: impl Fn(&mut ItemUse) -> bool + Send + Sync + 'static)`: The use button let go while using it (`use_until_released`, or before `use_ticks` ran out): `u.held_ticks()` is how long it was held. True if it did something. [source](https://github.com/Weft-Rust/Weft/blob/master/crates/sdk/src/content.rs#L2788)
- <a id="ItemBuilder-remainder"></a>`.remainder(item: &crate::Item)`: What is left of it when it is used up (a potion's bottle, fuel's bucket). [source](https://github.com/Weft-Rust/Weft/blob/master/crates/sdk/src/content.rs#L2796)
- <a id="ItemBuilder-gives_effect"></a>`.gives_effect(effect: &crate::EntityEffect, level: u32, secs: f32)`: Used, it gives `effect` at `level` for `secs` (`f32::INFINITY` for good; a potion: with `.use_ticks(32)` and `.remainder(&GLASS_BOTTLE)` that is all of it); several for several effects. It turns into its remainder, or one fewer; with an `on_use` of its own (eating) that does the rest and these come when it goes through. [source](https://github.com/Weft-Rust/Weft/blob/master/crates/sdk/src/content.rs#L2803)
- <a id="ItemBuilder-attack_speed"></a>`.attack_speed(per_second: f32)`: Full swings per second: hitting sooner does less (a sword 1.6, an empty hand 4). [source](https://github.com/Weft-Rust/Weft/blob/master/crates/sdk/src/content.rs#L2808)
- <a id="ItemBuilder-attack_damage"></a>`.attack_damage(damage: f32)` [source](https://github.com/Weft-Rust/Weft/blob/master/crates/sdk/src/content.rs#L2811)
- <a id="ItemBuilder-places"></a>`.places(block: &Block)` [source](https://github.com/Weft-Rust/Weft/blob/master/crates/sdk/src/content.rs#L2814)
- <a id="ItemBuilder-wearable_model"></a>`.wearable_model(slot: &EquipmentSlot, model: &str, bone: &str)`: Worn in equipment `slot`, where it shows as `model` on the wearer's bone `bone`, moved by what plays on the wearer, like `Registry::bone_model`: a tail only those who wear it have. [source](https://github.com/Weft-Rust/Weft/blob/master/crates/sdk/src/content.rs#L2819)
- <a id="ItemBuilder-tab"></a>`.tab(tab: &CreativeTab)`: Creative inventory tab, see `Registry::creative_tab`. [source](https://github.com/Weft-Rust/Weft/blob/master/crates/sdk/src/content.rs#L2827)
- <a id="ItemBuilder-no_tab"></a>`.no_tab()`: In no creative tab nor its search, still obtainable (`.untag(abi::comp::NO_TAB)` brings it back). [source](https://github.com/Weft-Rust/Weft/blob/master/crates/sdk/src/content.rs#L2832)
- <a id="ItemBuilder-wearable"></a>`.wearable(slot: &EquipmentSlot, inflate: f32, texture: &str)`: Worn in equipment `slot` (any mod's), where it shows on the wearer's model over the parts the slot covers: `texture` (under `entity/`, like `armor/iron_1`) in the wearer's skin layout, `inflate` pixels out from the body. [source](https://github.com/Weft-Rust/Weft/blob/master/crates/sdk/src/content.rs#L2838)
- <a id="ItemBuilder-spawns"></a>`.spawns(entity: &'static crate::EntityKind)`: Used on a block, puts `entity` on that side of it. One is used up, outside creative. Entities have an egg of their own without this; it is for something else that hatches one. [source](https://github.com/Weft-Rust/Weft/blob/master/crates/sdk/src/content.rs#L2847)
- <a id="ItemBuilder-on_use"></a>`.on_use(f: impl Fn(&mut ItemUse) -> bool + Send + Sync + 'static)` [source](https://github.com/Weft-Rust/Weft/blob/master/crates/sdk/src/content.rs#L2863)
